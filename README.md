# Sahil Merge Tool · Sync QC

Static web page for checking end-view / side-view rally sync, frame by frame.

1. Open the page in Chrome or Edge.
2. Choose the match zip (`…_match.zip`) from your computer. Nothing is uploaded; the videos are read from the zip on your disk.
3. For each rally: move the side view with `[` `]` (±1 frame) or `Shift+[` `]` (±5) until it matches the end view, then press `V` (verified → next rally). Progress is saved in this browser.
4. Click **Download QC results**: one zip with the full match sync-QC **JSON + XML** (`…_sync_qc.zip`). Send it back.
